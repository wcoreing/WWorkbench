# Demo 脚本（传播用）

录制前：深色主题、准备一台可 SSH 的主机或本机 Docker、侧栏助手已配置（或仅展示 MCP）。每条视频控制在 **30–60 秒**，字幕优先中文。

---

## 脚本 A — 主钩子（优先拍）

**标题建议**：Cursor 连上本地运维台：AI 能看到你 SSH 里在跑什么

1. 打开 WWorkbench，切到终端，SSH 进一台机器，跑一条会失败的命令（或 `docker ps` / 看日志）。
2. 侧栏 Ask：`刚才终端报错是什么意思？下一步怎么查？`
3. 展示助手能引用当前 Shell 上下文（或 Cursor 经 MCP 调用 `get_workbench_context`）。
4. 你按建议切到日志/数据库核对，**自己点确认**，不要让 AI 静默改机。
5. 收尾字幕：引导你做完，而不是替你点完。

---

## 脚本 B — 一张台

**标题建议**：别再开五个客户端排障了

1. 同一工作区依次点开：终端 → Docker → 数据库 → 笔记本。
2. 从容器一键连库（若有），在笔记本记一行结论。
3. 字幕：SSH / 库 / 容器 / 文件 / 日志，本来就串在一次事故里。

---

## 脚本 C — 本地与隐私

**标题建议**：运维台也可以不上云

1. 展示 `~/.wworkbench` 说明（或设置里本地存储文案）。
2. 关掉某项 AI 能力权限，再让助手调用被拒。
3. 字幕：连接与密钥留在本机；Agent 可选，权限你说了算。
